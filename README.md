# Python Word Guessing Game 🎮

## About the Project

This is a simple console-based word guessing game developed using Python. The computer randomly selects a word from a predefined list, and the player attempts to guess its letters.

## Features

* Random word selection
* Five predefined words
* Maximum of six incorrect guesses
* Tracks previously guessed letters
* Input validation
* Win and lose conditions
* Simple console interface

## Technologies Used

* Python

## Python Concepts

* Variables and data types
* Lists and strings
* Random module
* While and for loops
* If-else statements
* User input
* Built-in functions

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python word_guessing_game.py
```

## Learning Objective

This project was created to practise Python fundamentals, conditional logic, loops, lists, and user input handling.
